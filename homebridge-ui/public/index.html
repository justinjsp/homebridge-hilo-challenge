Hilo login / Connexion à Hilo

…

This plugin has its own Hilo login. It never uses homebridge-hilo's token, so the two plugins can't sign each other out.
Ce plugiciel a sa propre connexion à Hilo. Il n'utilise jamais le jeton de homebridge-hilo : les deux plugiciels ne peuvent donc pas se déconnecter l'un l'autre.

  1. Choose Log in to Hilo and sign in with your Hilo account in the window that opens.
    Choisissez Se connecter à Hilo, puis connectez-vous avec votre compte Hilo dans la fenêtre qui s'ouvre.
  2. You'll land on a My Home Assistant page that asks for a Home Assistant URL. That's expected, and you don't need Home Assistant. Don't type anything on that page and don't click Save.
    Vous arriverez sur une page My Home Assistant qui demande l'adresse de Home Assistant. C'est normal, et vous n'avez pas besoin de Home Assistant. N'inscrivez rien sur cette page et ne cliquez pas sur Save.
  3. Instead, copy the whole address from the browser's address bar at the top of that window. It starts with https://my.home-assistant.io/redirect/oauth?code=. Paste it below and choose Finish within a few minutes, before the code expires.
    Copiez plutôt l'adresse complète qui figure dans la barre d'adresse du navigateur, en haut de cette fenêtre. Elle commence par https://my.home-assistant.io/redirect/oauth?code=. Collez-la ci-dessous, puis choisissez Terminer dans les minutes qui suivent, avant que le code expire.

No login window? Open the Hilo login.
Aucune fenêtre de connexion? Ouvrir la connexion à Hilo.
